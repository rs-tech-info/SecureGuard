# 🛡️ SecureGuard - Anti-Fraud Protection App

SecureGuard aapke phone ko financial fraud, OTP theft, aur scam calls se bachata hai.

## ✅ Features

| Feature | Description |
|---|---|
| 🔍 App Scanner | Sabhi apps scan kare, risky permissions dhundhe |
| 📱 OTP Protection | Fraud SMS detect kare jo OTP maange |
| 📞 Call Protection | Suspicious/spoofed calls pe alert |
| 🔗 Link Detector | Phishing links detect kare |
| 👁️ Screen Monitor | Screen sharing apps se OTP chori rokta hai |
| 🔔 Notification Guard | Fraud notifications detect kare |
| 🚨 Real-time Alerts | Full screen warning jab fraud detect ho |
| 🏃 Auto-start | Phone reboot pe automatic start |

## 📲 GitHub Se APK Banane Ka Tarika

### Step 1: GitHub Account Banao
- [github.com](https://github.com) pe free account banao

### Step 2: New Repository Banao
- "New Repository" click karo
- Name: `SecureGuard`
- Public/Private koi bhi
- Create Repository click karo

### Step 3: Files Upload Karo
- Sabhi files GitHub pe upload karo (same folder structure maintain karo)
- Commit karo

### Step 4: APK Automatically Build Hogi!
- `Actions` tab pe jao GitHub pe
- "Build SecureGuard APK" workflow run hoga automatically
- Kuch minutes mein APK ready ho jayegi
- `Artifacts` section mein download karo

---

## 📱 Install Karne Ka Tarika

1. APK download karo
2. Phone mein `Settings → Security → Unknown Sources` enable karo
3. APK install karo
4. App open karo
5. Required permissions do:
   - SMS read permission ✅
   - Phone state permission ✅  
   - Notification access (Settings → Notification Access → SecureGuard) ✅
   - Accessibility Service (Settings → Accessibility → SecureGuard) ✅

## 🆘 Fraud Hone Pe Kya Karo?

1. **1930** pe call karo — National Cyber Crime Helpline
2. **cybercrime.gov.in** pe report karo
3. Apni bank ko turant inform karo
